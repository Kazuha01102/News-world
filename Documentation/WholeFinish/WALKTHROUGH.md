# NightHome 実機確認チェックリスト

今回はまだ実施していません。以下をまとめて試すためのチェックリストです。最初はデスクトップで1人、その後VR、最後に複数人で同じ順番を回ると比較しやすくなります。

記録欄：確認日＿＿＿＿／コミット＿＿＿＿／デスクトップ・VR＿＿＿＿／人数＿＿＿＿／音声出力先＿＿＿＿

## 0. 起動

- [ ] ALCOMのNightHomeからUnityを開く。
- [ ] Project欄の `Assets > NightHome > NightHome_Blockout` をダブルクリック。
- [ ] `VRChat SDK > Show Control Panel > Builder > Build & Test` でローカル起動。Uploadは使用しない。
- [ ] 実機確認用のビルドはこの仕上げ後のシーンであることを確認する。

## 1. 入口 → ログ・入退室音

- [ ] スポーンで床に埋まらず、壁・収納・マットに引っかからない。
- [ ] 入口ドア周辺、廊下へ向かう通路を歩く。ドアは装飾で開閉しない。
- [ ] ドア横のログが読め、時刻がJST／日本時間と分かる。
- [ ] 初回読み込み時に音が大量に重ならず、既存プレイヤー全員を新規入室として誤記録しない。
- [ ] 入退室音の音量とON/OFFを操作し、自分の設定として効く。
- [ ] 複数人試験では、入室／退室で別の短い音が鳴り、名前・時刻・種別が記録される。
- [ ] 途中参加でも直近ログが表示され、上限を超えた古い記録が消える。

## 2. リビング → ニューステレビ

- [ ] ソファ脇とテーブル周囲を歩き、脚・ラグ・家具の角で引っかからない。
- [ ] グレーの布、木目、床の板幅、植物の葉の表裏、窓の枠と夜景を確認する。
- [ ] 各ソファ付近からニュース映像・字幕・操作パネルを読める。
- [ ] 近づくと音声が聞こえ、各自の音量・消音が操作できる。
- [ ] 再生・停止・再接続、必要なら登録済み予備URLと手動URL入力を試す。
- [ ] 複数人ではチャンネル・再生状態が共有され、個人の音量・消音が他人に影響しない。
- [ ] 途中参加でチャンネルや再生が勝手にリセットされない。
- [ ] 操作者退出・所有権移譲後も共有操作が継続する。

ニュースURLの外部自動取得は未完成です。今回の確認は既存の登録URLと手動操作が対象です。

## 3. 描画スペース → QvPen → ローカルミラー

- [ ] 返却台へ近づけ、ペンと既存の操作部が見やすい。
- [ ] ペンを持ち、描画ボードや描画スペースで線を描く。
- [ ] 公式QvPen Prefabの消去・返却操作を試し、机とペンの位置がずれない。
- [ ] 他の人から線が見え、途中参加者にも復元される。
- [ ] 本棚がミラー前を塞がず、スイッチへ近づける。
- [ ] 初期状態でミラーがOFF。
- [ ] スイッチをUseしてON→OFFにできる。VR入力でも確認。
- [ ] 自分の操作が他人のミラー表示を変えず、他人の操作も自分に影響しない。

## 4. 廊下 → 寝室

- [ ] 廊下と寝室の枠を通り、頭や肩が引っかからない。
- [ ] ベッドの左右・足元へ移動でき、サイドテーブルとの間で動けなくならない。
- [ ] 枕・掛け布団・マットレスの浮きや大きな食い込み、角張った陰影がないか見る。
- [ ] ベッド上へ移動したときの足元と当たり判定を確認する。
- [ ] ベッドサイドの明るさが落ち着ける程度で、隣の部屋との差が極端でない。
- [ ] カーテンの裏が消えず、窓台や壁に大きく食い込まない。
- [ ] 立った目線・ベッド上の低い目線から窓外が夜景に見える。

今回のベッドとソファにUseで寝る・座るStationは追加していません。座面マーカーは配置用です。

## 5. 廊下 → 個室 → 室外へ戻る

- [ ] 入口の「個室」と人数表示が読め、出入りで人数が更新される。
- [ ] ソファ5座面と床クッションの周囲、テーブル脇、出口まで歩ける。
- [ ] 室内の人同士は会話できる。
- [ ] 室内→室外、室外→室内の両方向で声が抑制される。
- [ ] 室内ではテレビと入退室音が消える。
- [ ] 室外へ戻ると声とテレビ・入退室音が、それぞれの個人設定に従って戻る。
- [ ] 境界付近で前後に動いても、不自然な切り替えが続かない。
- [ ] 室内への途中参加、室内からリスポーン、プレイヤー退出後を確認する。

この音声分離はワールド側の制御です。完全な防音・プライバシーは保証しません。

## 6. VR → 複数人 → 最大16人の確認

- [ ] 同じ巡回をVRで行い、目線・手の届く高さ・Use・UI操作・描画を確認する。
- [ ] 人が分散した状態とリビングへ集まった状態を試す。
- [ ] 16人想定で通路が詰まらず、各部屋へ出入りできる。
- [ ] ミラーOFFとONで動作の重さを比較する。
- [ ] テレビ再生中・QvPen描画中・個室の音声処理中の負荷を確認する。
- [ ] 特定のアバターを変更しても再現する問題かを切り分ける。
- [ ] 再入室後にもミラー初期OFF、入退室音の初期抑制、テレビの途中参加動作を確認する。

影の負荷が問題になる場合は、UnityのHierarchyで `HOME - Plant and wall finish > Living contact shadow - one spot` を選び、そのLightをOFFにしたローカルビルドと比較できます。ほかのライトの影をまとめてONにしないでください。
